# Keyboard Visualizer

A responsive, interactive virtual keyboard built with HTML, CSS, and JavaScript.

## 🌍 Live Demo

Check out the live project here: 
**[https://keybod.netlify.app/](https://keybod.netlify.app/)**

## ✨ Features
- On-screen virtual keyboard with sound feedback
- Emoji panel integration
- Real-time word suggestions and autocomplete
- Light and Dark mode toggle
- Swipe-to-type functionality support

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
