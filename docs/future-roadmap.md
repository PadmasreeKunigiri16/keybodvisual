# KeyBod Visual — Future Roadmap

## Planned Enhancements
1. **PWA Offline Support**: Add Service Worker registration for full offline PWA installation.
2. **Multi-Language Dictionaries**: Expand suggestion engine to support Spanish, French, German, and Hindi word datasets.
3. **Bluetooth Hardware Telemetry**: Integrate Web Bluetooth API for custom mechanical keyboard telemetry.
4. **Custom Sound Font Upload**: Allow users to import custom audio click samples.
