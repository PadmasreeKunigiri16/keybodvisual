# KeyBod Visual — Privacy & Data Sovereignty

## Privacy Policy & Principles
- **No Third-Party Telemetry**: KeyBod Visual contains zero tracking scripts, analytics pixels, or remote keystroke logging APIs.
- **Local Browser Execution**: All word suggestion tries, spell check Levenshtein calculations, and audio synthesizers run entirely inside the client browser.
- **Data Portability**: Users can export 100% of their local state to a downloadable JSON file.
- **Instant Data Erasure**: Users can purge all local storage data with a single button click.
