# KeyBod Visual — Features Guide

## 1. Smart Virtual Keyboard & Physical Synchronization
- Interactive on-screen QWERTY, DVORAK, COLEMAK, and NUMERIC layouts.
- Hardware key synchronization: Pressing physical keys on a laptop or desktop highlights the corresponding screen keys with active ripple effects.
- Mouse Swipe-to-Type gesture support.
- Offline synthesized audio feedback (Mechanical, Chiclet, Typewriter, Beep, Silent).

## 2. Real-time Typing Area & Metrics Engine
- Real-time gross WPM, net WPM, accuracy %, character counter, word counter, mistake count, backspace tracker, and session duration clock.

## 3. Local Smart Word Suggestions & Spelling Assistant
- Client-side autocomplete bar predicting upcoming words.
- Levenshtein-distance spelling assistance highlighting typos (e.g. "teh" -> "the").
- Custom personal dictionary management (Add, Remove, Clear).

## 4. Typing Practice System
- Beginner, Intermediate, and Advanced difficulty tiering.
- Categories: Common words, Sentences, Programming code snippets (JavaScript, TypeScript, React, Algorithms), Quotes, Custom text input.
- Detailed completion modal with WPM, accuracy, time breakdown, and retry capability.

## 5. Visual Keyboard Heatmap & Analytics Dashboard
- Interactive Recharts line and bar graphs showing WPM growth trends and accuracy over time.
- Visual Keyboard Heatmap switching between **Usage Frequency** and **Error Heatmap**.
- Stats ranking top used keys and most error-prone keys.

## 6. Accessibility & Simple Mode
- High Contrast theme mode.
- OpenDyslexic font toggle for readers with dyslexia.
- One-Handed mode (Left or Right shifted layout).
- Large key buttons and focus ring indicators.
- **Simple Mode**: Minimalist interface stripping away complex charts for clean legibility.

## 7. Customization Studio
- Custom key height (40px to 70px), gap spacing (2px to 10px), font size, key shape (rounded, square, pill), audio profiles, and themes (Dark, Clean Light, High Contrast, Cyberpunk).

## 8. Emoji, Kaomoji & Symbol Center
- Categorized picker for emotions, gestures, tech symbols, kaomojis, and math symbols with copy and insert capabilities.

## 9. Privacy Center & Data Backup
- Local-first browser privacy assurance.
- One-click JSON backup export and data purge capability.
