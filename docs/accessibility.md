# KeyBod Visual — Accessibility (A11y) Guide

## Standards Compliance
KeyBod Visual is designed in accordance with Web Content Accessibility Guidelines (WCAG 2.1 AA):
- **Semantic HTML**: All buttons, inputs, region containers, and navigation items use appropriate native HTML tags.
- **ARIA Attributes**: `role="dialog"`, `role="switch"`, `aria-checked`, `aria-label`, and `aria-modal` attributes are integrated on custom interactive controls.
- **Focus Indicators**: Visible focus rings with high-visibility contrast ratios are enforced across all interactive components.
- **Dyslexia Support**: Native support for OpenDyslexic font faces to prevent character mirroring and reading fatigue.
- **High Contrast Theme**: Pure black (#000000) background with high-contrast yellow (#FFFF00) text and focus borders.
- **One-Handed Typing**: Shifted grid layout alignment for users with limited motor range or single-hand device usage.
- **Simple Mode**: Reduces cognitive load by hiding non-essential widgets and presenting enlarged controls.
